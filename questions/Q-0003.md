# Q-0003 — Should the order card still show the order number and item count?

## Question

Today's My orders list shows each order's number, item count and total. The
new card, as the issue describes it, shows the date, a status chip and the
total (LIN-GTB-3). For now the card drops the order number and item count, and
the order number is shown on the order screen (DEC-0001). Should the card keep
either of them?

## Pitanje

Današnji popis Moje narudžbe prikazuje broj narudžbe, broj stavki i ukupan
iznos. Nova kartica, kako je zadatak opisuje, prikazuje datum, status i ukupan
iznos (LIN-GTB-3). Zasad kartica izostavlja broj narudžbe i broj stavki, a broj
narudžbe prikazuje se na zaslonu narudžbe (DEC-0001). Treba li kartica
zadržati nešto od toga?

## Why it matters

FR-0001.AC-1 fixes what the card shows. A customer who quotes an order number
to the shop would have to open the order to find it.

## Options we see

- Date, status and total only (current default, DEC-0001).
- Add the order number to the card.
- Add the order number and item count to the card.

## Suggested answer

A guess: the Figma card (not yet available, Q-0001) settles it; until then,
date, status and total as the issue lists them.
