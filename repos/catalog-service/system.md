# catalog-service — place in the system

The product catalog of Shopfront: products, categories and prices with
history (`README.md:3`, `pom.xml:17`). A Spring Boot REST service with its
own PostgreSQL database.

## What it serves

A JSON REST API. Not found: any authentication or authorization; no
security dependency in `pom.xml` and no security configuration in the code.

| Method | Path | What | Source |
|---|---|---|---|
| GET | `/api/products` | Search: `categoryId`, `q`, `activeOnly` (default `true`), `page` (default 0), `pageSize` (default 20, max 200). Returns `ProductPage` | `web/ProductController.java:37-45` |
| GET | `/api/products/{id}` | One product, with `price` = the price valid now or `null` | `:47-50` |
| POST | `/api/products` | Create (201); optional initial `price` | `:52-56` |
| PUT | `/api/products/{id}` | Update name, description, category, active | `:58-61` |
| GET | `/api/products/{id}/prices` | Price history, newest first | `:63-67` |
| POST | `/api/products/{id}/prices` | Add a price (201), optional `validFrom` | `:69-73` |
| GET | `/api/categories` | All categories, by name | `web/CategoryController.java:31-36` |
| POST | `/api/categories` | Create (201) | `:38-46` |
| GET | `/v3/api-docs` | OpenAPI 3.0 spec (springdoc) | `application.properties:13`, `OpenApiSpecExportTest.java:33` |
| GET | `/swagger-ui/index.html` | Swagger UI | `README.md:20` |
| GET | `/actuator/health`, `/actuator/info` | Actuator; health probes enabled | `application.properties:17-18` |

Paths of Java files are under `src/main/java/com/shopfront/catalog/`.
Errors (4xx) use one body, `ErrorResponse { error, message, fieldErrors, timestamp }`
(`web/ErrorResponse.java`).

It has no screens of its own.

## What it calls

- **PostgreSQL**, through JPA. URL, user and password from `DB_URL`,
  `DB_USER`, `DB_PASSWORD`, with local defaults
  (`src/main/resources/application.properties:4-6`, `README.md:16-17`).
  Flyway migrates the schema at start-up (`spring.flyway.enabled=true`).
- Not found: calls to other services, queues, caches or external APIs.

## Who uses it

From the README only; the code of these clients is not in this repository.

- **Web and mobile clients** copy the generated `catalog.json` into their
  `specs/` folder (`README.md:31-32`). The web app shows
  `ErrorResponse.message` (`web/ErrorResponse.java:6`).
- **orders-service** relies on `price` in `GET /api/products/{id}`
  (`README.md:36-38`).

## Contracts shared with other repositories

- **OpenAPI spec** `target/openapi/catalog.json`, generated by
  `./mvnw -Popenapi test` and uploaded by CI as the artifact
  `catalog-openapi` (`.github/workflows/ci.yml:22-27`). Pinned to OpenAPI
  3.0, keys sorted, JSON only (`application.properties:11-15`). Spec info
  version "2.1" (`config/OpenApiConfig.java:10`). The spec is not committed
  to this repository; clients keep their own copies.
- **`ProductResponse.price`**: the current price or `null`, relied on by
  orders-service.

## Configuration

`src/main/resources/application.properties`, overridden by environment
variables:

| Variable | Default | Use |
|---|---|---|
| `PORT` | `8081` (the Docker image sets `8080`, `Dockerfile:12`) | HTTP port |
| `DB_URL` | `jdbc:postgresql://localhost:5432/catalog` | JDBC URL |
| `DB_USER` | set in `application.properties:5` | DB user |
| `DB_PASSWORD` | set in `application.properties:6` | DB password |

Tests use the Spring profile `test` (`src/test/resources/application-test.properties`):
in-memory H2 in PostgreSQL mode, Spring and Hibernate logging at WARN.

## Build and deployment

- **CI** (`.github/workflows/ci.yml`), on push and pull request to `main`:
  JDK 17 Temurin; `./mvnw -B verify`; `./mvnw -B -Popenapi test`; upload of
  the spec. On `main` only, a second job builds the Docker image tagged with
  the commit SHA. The image is not pushed anywhere (TODO at `ci.yml:37`).
- **Docker** (`Dockerfile`): multi-stage. Builds with
  `eclipse-temurin:17-jdk` (`dependency:go-offline`, then
  `package -DskipTests`), runs on `eclipse-temurin:17-jre` as
  `java -jar /app/catalog-service.jar`, port 8080, `HEALTHCHECK` with
  `curl` against `/actuator/health`.
- Not found: deployment manifests (Kubernetes, Compose, Helm), environments,
  a registry, or release tagging in this repository.
