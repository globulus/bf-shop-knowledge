# FR-0005 — My orders and order screen follow the Figma design's spacing and type

## User story

As the shop, I want the new My orders and order screens to look as designed, so
that the app matches the design the client signed off.

## Context

> "Design is done: https://www.figma.com/design/V6zOfKbNI3wPTVJBs02Jwd/Mobile-App?node-id=4687-11685"
> — LIN-GTB-3

> "Check the Figma for spacing and type, I won't repeat it here." — LIN-GTB-3

The issue states the visual detail only by reference to the Figma file. The
frames taken in with it (`inputs/attachments/LIN-GTB-3/`, eight of more) show
an unrelated product: frames "i" and "Local components" are section titles and
a component sheet of people, messages, navigation and video calls; "Active
Collab Card" shows a "Today" calendar screen; "Virtual rooms" shows a "Campus"
chat list. None shows an order card, a month header, a status chip or an order
screen. No testable criterion for spacing and type can be written from them, so
this requirement waits on Q-0001 (maintainer): the frames of node 4687-11685
that show My orders and the order screen.

## Acceptance criteria

### AC-1 — Matches the design frames

- **Given** the My orders frames of the Figma design, once taken in (Q-0001)
- **When** the My orders list and the order screen are compared with them in
  light mode
- **Then** spacing, type sizes and weights, and the chip colours' exact shades
  match the frames

## Out of scope

- Dark mode: "Dark mode is in the file too but can be a follow-up." — LIN-GTB-3
  (DEC-0005).
