# FR-0002 — Order screen with the order's lines

## User story

As a customer using the mobile app, I want to open an order and see what is in
it, so that I can check the products, quantities and amounts I ordered.

## Context

The app has no order screen today:

> "Tapping a card opens the order with its lines (product name, quantity, line
> total). We don't have this screen at all today." — LIN-GTB-3

> "The order detail needs `GET /api/v1/orders/{id}`, which the app's generated
> client already has." — LIN-GTB-3

So the screen reads the order through the existing endpoint and its generated
client; no API change is part of this requirement.

Decided by default (DEC-0003), the client may still change it: above the lines
the screen shows the order's number, date, status chip (as on the card,
FR-0001.AC-2) and total; lines appear in the order the API returns them; the
amounts shown are those the API returns, the app computes none; while the
order loads the screen shows a loading indicator, and if it can't be loaded, a
localized error message with a way to try again.

## Acceptance criteria

### AC-1 — Order header

- **Given** a customer on My orders
- **When** they tap an order's card
- **Then** the order screen opens and shows that order's number, date, status
  chip and total (DEC-0003)

### AC-2 — Order lines

- **Given** an order with one or more lines
- **When** its screen is open
- **Then** each line shows its product name, quantity and line total, in the
  order `GET /api/v1/orders/{id}` returns them

### AC-3 — Data source

- **Given** the customer taps an order's card
- **When** the order screen loads
- **Then** the app fetches the order with `GET /api/v1/orders/{id}` through the
  app's generated client, and the amounts shown are the ones in the response,
  unchanged (DEC-0003)

### AC-4 — Load failure

- **Given** the order cannot be loaded (no connection, or an error response)
- **When** the customer opens its screen
- **Then** the screen shows a localized error message and a way to try again,
  and trying again once the order can be loaded shows it as in AC-1 and AC-2
  (DEC-0003)

### AC-5 — Back to the list

- **Given** an open order screen
- **When** the customer goes back
- **Then** the My orders list is shown again

## Examples

The app shows what the API returns (made-up order):

| Line from the API | Shown as |
|---|---|
| product "Hand grinder", quantity 1, line total 89.00 | Hand grinder · 1 · 89.00 in the app's currency format |
| product "Paper filters 100", quantity 3, line total 14.70 | Paper filters 100 · 3 · 14.70 in the app's currency format |
| order total 103.70 | header total 103.70 |

## Out of scope

- Any change to `GET /api/v1/orders/{id}` or the orders-service.
- Cancelling from this screen is FR-0003.
- Visual detail per Figma is FR-0005; dark mode (DEC-0005).
