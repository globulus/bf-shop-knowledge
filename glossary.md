# Glossary

Every domain term, in Croatian and English, with the name code must use. New
terms are added by the synthesizer and reviewed in the PR that adds them.

| Croatian | English | Code name | Definition | Source |
|---|---|---|---|---|
| napomena za dostavu | delivery note | `deliveryNote` | Optional free text of at most 280 characters that a customer writes when placing an order, with instructions for its delivery; stored with the order and never changed afterwards. Not a dispatch document (otpremnica). | LIN-GTB-2 |
| Moje narudžbe | My orders | — | The app's list of the customer's orders (an existing screen; its code name is whatever the mobile repo already uses). | LIN-GTB-2 |
